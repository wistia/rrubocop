# Shared source-analysis reuse

Base: `8d4780e` (validated implementation source `0a46f7d`). This branch addresses repeated file-processing audit R1, shared heredoc work in R5 and bounded configuration work in R7. It does not remove safety checks or change rule coverage.

* Capture-observer checks now memoize the existing predicate by enclosing scope byte range and kind for each immutable SourceFile. All seven existing consumers share positive and negative results. Nested method/class exclusions, indirect last_match calls and scope selection remain exact; this deliberately does not substitute Performance/RegexpMatch's different ordered-observer semantics.
* One iterative, source-owned heredoc index supplies sorted opener/body ranges, interpolation offsets, unique-delimiter bodies and same-line opener queries. FileRead/FileWrite replacement suffixes retain the original sorted positional zip and output ordering while using binary lookups for referenced openers. Eval location retains its unique-delimiter and lexical fallbacks. Static heredoc decoding and interpolation checks reuse the same source facts; recovered/error-tree interpolation lookup retains the original walk fallback. Cached structures contain byte metadata rather than borrowed native nodes.
* FindEach keeps the default empty-pattern fast path, then snapshots the complete effective AllowedPatterns option per source. Valid compiled pattern lists are shared across files only within a lint operation, preserving list order and invalid-pattern skipping. LineLength uses the same operation-scoped preparation. Empty lists reuse one immutable empty value. Operation lifetime tests prove refresh between invocations and exact pattern-list identity.

R7's SpecFilePathFormat lead was overbroad: its program callback requires exactly one eligible top-level group and compiles a generated pattern at most once per file. An unbounded speculative generated-pattern cache would retain mostly unique values without established reuse, so no source change is made there. Existing per-source prepared Naming/ContextWording/GraphQL settings are retained; this branch does not claim a generalized configuration-preparation redesign. Other audit findings have separate owners.
